# DESPACHANTE CAC PROF

PWA especializado em despachantia para CAC, Porte, Posse de Arma, Autorização de Compra e documentos relacionados.

## Iniciando

1. Clone o repositório:
```bash
git clone https://github.com/professor100destino-boop/despachante-cac-prof.git
cd despachante-cac-prof
```

2. Instale dependências:
```bash
npm install
```

3. Configure o banco de dados (execute em https://supabase.com/dashboard):
   - Abra o arquivo `setup_database.sql`
   - Cole o conteúdo no SQL Editor do Supabase
   - Clique em "Run"

4. Inicie o desenvolvimento:
```bash
npm run dev
```

5. Abra http://localhost:3000

## Stack

- React 18
- TypeScript
- Tailwind CSS
- Supabase (PostgreSQL + Auth)
- Vite
- PWA (Progressive Web App)
